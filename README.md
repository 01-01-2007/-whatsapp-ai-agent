# Agente WhatsApp AI - Angola

AI Agent for WhatsApp built with Llama 4 (Meta Model API) to automate sales for African SMEs.

## O Problema
90% das empresas em Angola vendem no WhatsApp e perdem clientes por demora.

## A Solução
Um funcionário de IA que:
- Entende Português + gírias angolanas
- Atende 24/7
- Gerencia catálogo e fecha vendas automaticamente

## Tech Stack
- Llama 4 via Meta Model API
- WhatsApp Business API
- Python + LangChain + Vector DB
